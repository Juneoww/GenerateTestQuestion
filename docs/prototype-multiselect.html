3 本次生成

设计要点（为什么这样摆）
  • 整卡可点、选中态高亮：勾选目标从 15px 小方块扩大到整张卡片；选中后描边＋浅蓝底，隔着屏幕也能确认选了什么，不依赖小勾本身。
  • 分组即导航：16 个站点按中文/英文分两排；31 个小类收进各自大类卡片里，"大类→小类"的层级直接用版面表达，代替旧版的一整片平铺。
  • 大类可折叠：默认收起只占五行，点标题展开小类；折叠后徽章仍显示"已选 n/m"，三态框照常可整组勾选，省空间不丢信息。
  • 三态父框：大类勾选框有 全选✓／部分—／全不选 三态，部分选中时用户不会误以为整组都选了或都没选。
  • 计数徽章实时反馈：每个区块头部有"已选 n/m"，第 3 步汇总一行随时念出当前选择，选没选够不用回头数。
  • 快捷操作：全选/清空/全选中文/全选英文/清空本组，常见批量意图一步到位。
  • 非法组合禁用：0 个网站或 0 个小类时"开始生成"置灰，并在下方用红字说明缺什么。
  • 桌面端落地：ttk.Checkbutton 自带 alternate 三态；卡片高亮用 style.map 即可，无需引入新依赖。
