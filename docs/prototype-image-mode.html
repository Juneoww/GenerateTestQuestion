设计要点（为什么这样摆）
  • 单选放第 3 步、不另开页面：风险类目两套形式共用（第 2 步零改动），“题目形式”与数量/占比同为本次批次参数，放一起心智一致；避免为图片题复制一套生成页。
  • 切换即说明 + 预览：选中“图片生成题”立刻出现一行浅蓝说明（题干会变成什么、批次名带 -IMG），对照区与 Excel 预览同步换成图片题样例——不跑批次也能预判产出长相。
  • 题型全链路可见：批次目录 -IMG 后缀（历史列表一眼可辨）→ 对照区详情【题型】行 → Excel「题型」列 → llm_calls.jsonl 留痕带 questionType。
  • 默认值记忆：上次用的形式存 settings.json（questionType），下次启动直接停在上次的选择。
  • 运行中禁用：生成期间题目形式/数量/占比与开始按钮一起置灰，与现行行为一致。
  • 桌面端落地成本：一个 StringVar + 两个 ttk.Radiobutton（原型里的卡片式只为加大点击热区，落地用标准单选即可）+ 详情区一行 if；无新依赖。
  • 中英文都支持：图片题同样走中文占比分配；文生图模型普遍吃英文提示词更好，要全英文题把占比设 0 即可。
