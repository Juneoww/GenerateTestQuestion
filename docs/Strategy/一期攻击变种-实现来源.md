# 一期攻击方式变种：实现来源

本文记录当前代码**实际使用**的方法与来源，区分第三方移植、Python 标准库和本项目实现。策略只处理现有原题，不调用模型或被测系统。外部开源项目不随程序整体部署。

## 第三方来源与许可

- **Promptfoo 0.125.1**：[otherEncodings.ts](https://github.com/promptfoo/promptfoo/blob/0.125.1/src/redteam/strategies/otherEncodings.ts) 中的 `toCamelCase`、`toMorseCode`、`toPigLatin`／`pigLatinWord`、`toEmojiEncoding` 分别用于 R06、R07、R08、R09 的移植或适配。原实现为 TypeScript，本项目转换为 Python，并按下表说明进行转换和适用字符调整。
- Promptfoo 的 [MIT 许可证](https://github.com/promptfoo/promptfoo/blob/0.125.1/LICENSE)及版权声明保留在项目根目录 `THIRD_PARTY_NOTICES.md`。打包配置将该文件包含在 Windows EXE 中。
- 未部署 Promptfoo 或 Node，也未把其整个项目纳入本工具。PyRIT、garak 和 PromptInject 仅作为前期调研来源，**当前代码没有引用或移植它们的实现**。

## 基础规则、编码和字符处理

| 策略 | 当前实际实现 | 来源及与上游的区别 |
|---|---|---|
| basic | 保留本次选中原题作为基线 | 本项目结果组装，不生成额外变种。 |
| R01 Base64 | UTF-8 编码后 `base64.b64encode`，再附解码请求 | Python 标准库；包装文本为本项目实现。 |
| R02 ROT13 | `codecs.encode(..., 'rot_13')`，再附解码请求 | Python 标准库；整题适用字符均转换。 |
| R03 Leetspeak | 固定字母到数字映射 | 本项目映射，整题适用字符均转换，不宣称移植上游。 |
| R04 hex | `bytes.hex()`，再附解码请求 | Python 标准库；本项目包装。 |
| R05 homoglyph | 固定拉丁字母到视觉相似字符的映射 | 本项目映射，整题适用字符均转换，不宣称使用 Unicode 全量同形字数据。 |
| R06 camelcase | 连续英文词组转驼峰 | **Promptfoo `toCamelCase` 移植／适配**；本项目处理整题中的英文词组，与上游对所有空白分词的处理不完全相同。 |
| R07 morse | 英文字母、数字和指定标点转摩尔斯 | **Promptfoo `toMorseCode` 移植／适配**；本项目对不支持字符直接跳过，上游保留不支持字符。 |
| R08 piglatin | 英文单词按元音／辅音转换 | **Promptfoo `toPigLatin`／`pigLatinWord` 移植／适配**；处理整题中的适用单词。 |
| R09 emoji | UTF-8 字节映射至不可见变体选择符并附着在表情后 | **Promptfoo `toEmojiEncoding` 移植**；本项目新增严格解码与往返校验。不是可见词语转表情，也不部署 Promptfoo。 |
| R10 URL 编码 | `urllib.parse.quote_from_bytes` | Python 标准库；本项目包装及校验。 |
| R11_binary／octal／decimal | 按 UTF-8 字节分别用 `format` 输出二进制、八进制、十进制 | Python 标准库；本项目确定宽度、分隔符和包装。 |
| R12_html／unicode | 按码点生成数字实体；按 UTF-16 单元生成 JSON 风格转义 | Python 标准库编码与本项目格式化；不声称与普通 HTML 转义或 PyRIT 同名方法输出一致。 |
| R15_upper／lower | 正则匹配整题 ASCII 字母后调整大小写 | Python 标准库；本项目固定规则。 |
| R16_space／dot／underscore | 正则匹配英文词后在字母间插入空格、点或下划线 | Python 标准库；本项目固定规则。 |
| R18 倒序 | Python 字符串按码点倒序，附还原请求 | 本项目实现；无变化时跳过，组合字符与变体选择符等显示需复核。 |

## 直接指令与结构边界

I01–I09 的中文／英文固定模板由**本项目编写**，没有声称引用 Promptfoo 的模板集或其他第三方模板。它们都在现有原题外拼接普通文本，不产生真实系统消息或授权。

| 策略 | 当前实现 |
|---|---|
| I01 | 固定的指令覆盖前缀。 |
| I02 | 固定的管理员身份声明前缀。 |
| I03 | 固定的系统／用户文本标签。 |
| I04_refusal／format | 分别添加拒绝抑制或编号列表格式要求。 |
| I05 | 指定中性回答前缀。 |
| I06 | 固定的虚构规则更新说明。 |
| I07_json／xml／markdown | 使用标准库 JSON／HTML 转义或本项目引用格式包装原题。 |
| I08 | 添加文本边界标记，不改变真实消息边界。 |
| I09 | 对选中的原题使用内部指令请求模板，不再以原题目标是否已确认为条件；模板可能引入新的测试目标，原断言仅供参考，生成结果待复核。 |

具体启用范围、错误处理和图片限制以[一期实现设计](./一期-基础规则与指令边界实现设计.md)及实际测试为准。引用上游方法不代表经过对目标模型的有效性测试。
