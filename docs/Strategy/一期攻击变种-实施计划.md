# 一期攻击变种实施计划

> 任务按已确认的一期设计拆分，完成后以实际实现与验证结果更新来源记录。

**目标：**在三个结果工作区基于现有原题生成离线规则变种，导出同一 Excel 中的原题与全部变种，可选生成文字图片。

**架构：**独立 Python 策略引擎处理原题，结果页调用引擎并展示状态，独立导出模块生成 Excel、图片及追溯信息；保持原题生成和既有文件契约。R09 使用经许可按需移植的 Promptfoo 隐写方法，不依赖 Node 或调用模型。

**技术栈：**Python、Tkinter、openpyxl、Pillow、pytest；第三方代码仅按需提取并保留许可证。

## 任务

- [x] 针对规则编写行为测试，覆盖中文、英文、空值、边界、I09 模板，以及 R09 与 Promptfoo 0.125.1 对照及往返。
- [x] 实现独立策略目录和变换接口；保留原题，逐策略返回成功／不适用／失败及原因；不组合策略、不调用网络。
- [x] 针对合并 Excel 与图片写测试，覆盖原题行、变种行、跳过原因、文本字面值、图片位置、R09 图片例外和保存失败。
- [x] 实现独立导出模块；原始文件不变，Excel 同表展示原题和变种，文字图片重用现有配置及渲染器。
- [x] 在三个结果工作区接入选题、策略选择、生成、展示、复制和导出，并验证入口和窗口交互；现行范围对原题文本执行规则变换，不因风险编号、输入面或 I09 目标未确认而跳过。
- [x] 逐项记录策略来源、上游固定版本及文件、方法、改动、许可证和校验；未引用第三方源码的项目标明标准库或自有实现，不虚称引用。
- [x] 完成全量回归、桌面自检与 Windows 临时打包自检；测试退出阶段有 Tk 窗口销毁提示，测试结果为通过。
