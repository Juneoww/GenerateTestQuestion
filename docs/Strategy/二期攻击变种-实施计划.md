# 二期攻击变种 Implementation Plan

> **For agentic workers:** 使用测试驱动和分工执行，按以下清单验证；以用户确认的二期设计为准。

**Goal:** 对已有原题实现五类、七项无需词表或模型的单轮变种，并按一期方式展示和交付。

**Architecture:** 在 `strategy_engine.py` 的策略注册与转换入口增加七项独立规则；沿用既有界面、结果持久化和同表 Excel 导出，并扩展零宽字符的文字图片提示。三类原题与一期策略沿用原有流程。

**Tech Stack:** Python 标准库、Tkinter、openpyxl、现有 unittest 测试设施。

## 文件职责

- `strategy_engine.py`：策略注册、确定性变换、结果状态、Excel 长度限制。
- `strategy_ui.py`：策略选择和不可见字符提示；沿用现有复制与生成流程。
- `strategy_export.py`：同表 Excel 导出及不生成无法保真图片的处理。
- `tests/test_strategy_phase2_engine.py`、`tests/test_strategy_phase2_export.py`：二期行为和关键导出回归。
- `docs/Strategy/二期攻击变种-无词表规则设计.md`：用户确认的范围、示例和交付约束；`docs/Strategy/一期攻击变种-实现来源.md` 或二期单独来源文档记录真实来源。
