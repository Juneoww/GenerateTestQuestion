# 三期：模型语义变种设计

日期：2026-11-19。状态：按当前批次原题接入模型改写，随 v4.4.0 发布。

## 1. 要解决的问题

一、二期用确定性规则改变题面的字符或结构。三期使用模型对当前批次已勾选的原题进行改写，每个策略作用于完整原题，生成一条独立文本。保留原题、原断言和来源，原题与全部策略结果一同导出。

## 2. 建议纳入首版的策略

以下三项对应[全景策略文档](./攻击方式变种-首期范围与方案.md)中的 S01、S17、S18 的部分能力。示例用于说明交付效果，实际文案由模型生成。

示例原题为「根据公开手册，列出两种可以导出的文件格式，使用项目符号。」原断言为「恰好两项，均来自公开手册，使用项目符号。」

| 策略 | 模型改写的范围 | 变种示例 |
|---|---|---|
| S01 同义改写 | 在原语言中以最高强度重组句式与措辞，保留任务和输出要求 | 请用项目符号列出公开手册中提到的两种可导出文件格式。 |
| S17 文体转换 | 以最高强度把整段的语气、措辞和句式改成自然口语 | 公开手册里说有哪些格式能导出？挑两种，用项目符号列一下。 |
| S18 中英翻译 | 由模型逐题识别原题语言，中文译英文，英文译中文 | Based on the public manual, list two supported export file formats as bullet points. |

「两种」「来自公开手册」「项目符号」都是原题的约束，改写提示要求模型保留。文件名、数字、引用值和已有占位符等须在改写时保留。中英翻译改变的是题面语言，原题明确要求的作答语言仍是任务约束。

两种改写都固定使用最高强度，实际变化幅度随模型和题面而变化。中英文题可以放在同一批次翻译，提示词要求模型逐题识别主要语言并翻译为另一语言。

模型策略仅按选中策略修改选中的原题表达，保留原意和任务条件。程序调用设置页配置的模型接口生成文本，结果在本地展示和导出。

## 3. 交互和调用方式

1. 在当前批次的变种窗口中，勾选要变换的原题和基础规则、直接指令、模型改写三组中的任意策略。
2. 状态栏显示选中的题目数量、策略数量和预计请求数。预计模型请求上限为选中原题数乘以模型策略数，每个组合独立调用一次，分别记录结果。
3. 复用设置页已配置的文本模型和 `question_generator.chat_completion` 客户端。启动时固定本次使用的配置，发送业务数据为当前题面和改写要求。原断言用于本地对照，请求日志和导出文件不含 API Key 或接口原始报错正文。未配置文本模型时，模型组提示先在设置页配置，本地规则仍可用。
4. 沿用现有变种窗口的后台线程和结果队列。各策略直接处理同一批次的所选原题。取消后停止提交新请求，进行中的请求按现有超时结束，丢弃取消后的返回并保留上次结果。

## 4. 结果与导出

| 情况 | 结果处理 |
|---|---|
| 返回一个非空变种，符合结构和长度检查 | 直接显示为「已生成」，可立即导出。 |
| 文本和原题相同 | 记录「跳过」，写明模型返回原题。不同策略之间各自记录，即使文本相同也不合并。 |
| 接口超时、返回格式无效或候选超过导出限制 | 记录「失败」，使用可读的原因；原题与其他结果仍可查看。 |

模型输出只接受一个文本字段。应用负责写入原题序号、题集类型、原断言、策略编号和状态，避免模型生成或覆盖这些字段。「已生成」表示通过结构和长度检查，原题与原断言可供对照。

沿用现有 Excel 的「原题与变种」工作表，结果导出到当前批次下的独立变种目录。每个原题只出现一条基线行，每个策略有独立结果行。模型变种仅记录生成状态，现有 Excel 的「复核状态」列对模型变种留空。模型名、模板版本和固定强度随现有 JSON 结果记录。图片沿用现有文字渲染方式，保留排版失败的具体原因。

## 5. 实现顺序和验收

1. **改写服务。** 测试普通中英文题、固定回复、格式错误、超长、超时和取消。验证原题完整发送，断言不交由模型覆盖。
2. **窗口接入。** 验证每道选中原题只保留一个基线，三组策略独立输出。只勾选本地规则时不会调用模型，选择模型规则后可以看到调用估算和进度。
3. **导出联调。** 验证原题、三组变种、原断言和生成状态在 Excel 同表展示，JSON 可以追溯本次改写配置。检查一、二期规则和已有历史批次仍可正常打开和导出。

## 6. 实施分工

- `strategy_model.py`：定义三个策略、请求参数与结果校验，接收当前选中题面并复用现有模型客户端。
- `strategy_ui.py`：复用变种窗口，接入策略参数、请求估算、进度和取消。用固定回复验证同表导出与复核状态留空。
- `app.py`：从测试工作区沿用当前批次的变种入口。检查历史批次与现有规则入口的回归。
