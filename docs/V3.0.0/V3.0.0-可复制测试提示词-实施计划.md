# OWASP 可复制测试提示词 Implementation Plan

> **已被后续决策覆盖（2026-09-28）：** 此计划仍保留富 `testCase`、步骤和详情区。用户随后确认最终 JSON / Excel / 结果区必须仅保留四字段；请改用 [`V3.0.0-极简提示词输出-实施计划.md`](V3.0.0-极简提示词输出-实施计划.md)。

> **For agentic workers:** REQUIRED SUB-SKILL: Use `@test-driven-development` for the behavior change. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 OWASP 原型生成结果中的每一个 `stepType=prompt` 都是测试人员可直接复制到被测模型输入框的完整提示词。

**Architecture:** 保持一个 `testCase` 内的步骤、会话和断言关系不变，只替换 prompt 步骤的内容表达：`setup` 继续说明测试人员如何建立隔离账号与会话，`prompt.instruction` 只保存面向被测模型的直接输入。原型仍使用受控的内存模拟响应，不接入真实模型 API。

**Tech Stack:** Python 3.12、标准库 `tkinter` / `unittest`。

---

## 范围与验收

- **唯一首要验收：** 所有演示用例中的每个 `prompt.instruction` 都是完整、可直接发送的文本；LLM02 跨会话结果中的 A/B 两条分别等于用户确认的可复制文本；详情区明确标注“可复制提示词”。
- **测试数据：** `2356` 仅为无价值测试数据；不得替换为真实取件码、密码、个人数据或生产记录。
- **不包含：** 真实模型 API 调用、真实 Excel 导出、目标系统执行、其他 OWASP 风险的扩展。
