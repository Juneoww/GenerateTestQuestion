# V3 原生 Tkinter 原型 Implementation Plan

> **历史计划说明（2026-09-28）：** 本计划记录最初的富 `testCases` / Excel 三表原型。用户后来确认当前输出只保留 `userA`、`userB`、`prompt`、`assertion`；现行实现与验收以 [`V3.0.0-极简提示词输出-实施计划.md`](V3.0.0-极简提示词输出-实施计划.md) 和对应设计说明为准。

> **For agentic workers:** REQUIRED SUB-SKILL: Use `@test-driven-development` and desktop UI verification. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供一个独立、可运行的 Tkinter 原生原型，展示“一个桌面工具、TC260 与 OWASP 两个工作区、两条独立 pipeline”的 v3 信息架构及跨会话用例/Excel 三表关系。

**Architecture:** 不修改 `app.py`、`pipeline.py` 或任何 v2 生产行为。新增 `prototypes` 小包保存固定的安全演示数据与 Tkinter 窗口；纯函数模拟生成模型的严格 `testCases` JSON 响应，并负责校验跨会话模型、渲染用例详情、生成三张 Excel 预览表的行数据。GUI 从空结果状态开始，只有收到模拟模型响应后才显示用例。原型不访问网络、不调用真实模型、不爬取网页、不生成实际 Excel 文件。

**Tech Stack:** Python 3.12、标准库 `tkinter` / `unittest`；沿用现有 `ttk` 的 `clam` 主题和 Microsoft YaHei UI 字体。

---

## 范围与边界

- **包含：** 两个生成工作区、来源管理/设置的共享入口、OWASP 2026 十项风险清单、能力选择、模拟模型 `testCases` 生成、跨会话用例详情、模型 JSON 与三表 Excel 字段预览。
- **不包含：** 修改 v2、模型调用、爬虫、真实 Excel 导出、真实批次落盘、目标系统执行、PyInstaller 打包。
- **安全边界：** 演示内容只使用 `2356` 等无价值测试数据；不含真实密钥、个人数据、攻击载荷或可执行操作。

```python
from prototypes.v3_native_prototype import (
    build_demo_cases,

def test_cross_session_case_has_two_prompt_sessions():
    case = build_demo_cases()[0]
    assert validate_demo_case(case) == []
    prompts = [step for step in case["steps"] if step["stepType"] == "prompt"]
    assert [step["sessionId"] for step in prompts] == ["SESSION-A", "SESSION-B"]
    assert case["primaryRiskId"] == "LLM02"


def test_excel_preview_preserves_case_step_and_assertion_keys():
    case = build_demo_cases()[0]
    workbook = build_excel_preview_rows(case)
    assert list(workbook) == ["测试用例", "执行步骤", "执行记录"]
    assert workbook["测试用例"][0]["用例ID"] == case["caseId"]
    assert [row["会话标识"] for row in workbook["执行步骤"]][-2:] == ["SESSION-A", "SESSION-B"]
    assert {row["断言ID"] for row in workbook["执行记录"]} == {"A01", "A02"}
    assert "SESSION-A / T1" in render_case_detail(case)
```

## Task 3: 构建实际 Tkinter 原型窗口

**Files:**
- Modify: `prototypes/v3_native_prototype.py`

- [x] **Step 1: 在纯函数测试保持绿色的前提下新增 `V3PrototypeApplication(tk.Tk)`**

窗口应为 `1360x920`（最小 `1080x720`），使用 `clam` 主题，并在一个 `ttk.Notebook` 内呈现：

```text
TC260 题库生成 | OWASP 红队用例 | 来源管理 | 设置
```

其中：

- `TC260 题库生成` 说明其保留“网站素材 → 单条题目”的 v2 流程，不伪造完整生产页。
- `OWASP 红队用例` 是默认展示页，包含能力复选区、风险选择区、用例数/语言/授权确认区、初始为空的用例树与详情分栏。
- 点击“开始生成测试用例”后，模拟生成模型返回 `testCases` JSON；选择 `LLM02` 用例后，右侧显示两条跨会话提示和两个断言。
- 所有 `stepType=prompt` 的 `instruction` 必须是可直接复制并发送给被测模型的完整提示词；`setup` 等非 prompt 步骤仍可显示测试人员操作说明。
- `Excel 三表预览` 打开 `Toplevel`，以三个小表展示 `build_excel_preview_rows()` 的结果；只显示内存数据。
- `查看模型响应 JSON`、`生成跨会话测试用例`、用例树选择和能力快捷预设可更新状态文字，不访问网络。
