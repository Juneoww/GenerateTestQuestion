# V3 极简提示词输出 Implementation Plan

> **已被字段演进覆盖（2026-09-28）：** 用户随后确认必须保留并解耦风险编号、风险名称。当前实现和验收请以 [`V3.0.0-风险编号与名称解耦-实施计划.md`](V3.0.0-风险编号与名称解耦-实施计划.md) 及最新设计说明为准。

> **For agentic workers:** REQUIRED SUB-SKILL: Use `@test-driven-development` for each behavior change. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 OWASP 原型的最终 JSON、Excel 与结果区收缩为 `userA`、`userB`、`prompt`、`assertion` 四字段，直接服务可复制提示词生成。

**Architecture:** 原型不再保留或投影富用例对象。模拟生成器直接返回由四字段构成的 JSON 数组；验证器拒绝缺失、空白、不一致或额外字段。桌面结果区和 Excel 预览读取同一数组，Excel 只有 `测试提示词` 一个工作表。

**Tech Stack:** Python 3.12、标准库 `tkinter` / `json` / `unittest`。

- [x] **Step 2: 添加非法记录与 Excel 契约测试**

```python
def test_validator_rejects_extra_or_inconsistent_fields(self) -> None:
    assert validate_prompt_record({"userA": "", "userB": "", "prompt": "x", "assertion": "y", "condition": "z"})
    assert validate_prompt_record({"userA": "A", "userB": "B", "prompt": "not B", "assertion": "x"})
    assert validate_prompt_record({"userA": "", "prompt": "x", "assertion": "y"})
    assert validate_prompt_record({"userA": "A", "userB": "", "prompt": "x", "assertion": "y"})
    assert validate_prompt_record({"userA": "", "userB": "", "prompt": "  ", "assertion": "y"})
    assert validate_prompt_record({"userA": [], "userB": "", "prompt": "x", "assertion": "y"})
    assert validate_prompt_record({"userA": "", "userB": "", "prompt": 1, "assertion": "y"})
    assert validate_prompt_record({"userA": "", "userB": "", "prompt": "x", "assertion": None})

def test_excel_preview_uses_one_sheet_and_four_columns(self) -> None:
    workbook = build_excel_preview_rows(build_demo_prompt_records())
    assert list(workbook) == ["测试提示词"]
    assert list(workbook["测试提示词"][0]) == ["userA", "userB", "prompt", "断言"]
```

`validate_prompt_record()` 返回问题列表：空列表表示有效，非空列表表示必须拒绝，以上断言均应为真。
