# v3.0.1 打包爬虫数据修复设计

## 背景与目标

v3.0.0 的单文件 Windows 程序在 TC260 开始爬取时，BrowserForge 读取 `apify_fingerprint_datapoints/data/input-network-definition.zip` 失败。源码环境中该文件存在，发布包中缺失。v3.0.1 只修复发布包资源完整性，不改变 TC260、OWASP 的生成或导出行为。

## 方案

- 在 PyInstaller spec 中显式收集 `apify_fingerprint_datapoints` 的数据文件，保留当前单文件 GUI 打包方式。
- 扩展现有无界面 `--smoke-test`：检查该依赖的五个运行时数据文件是否真实存在；缺失时非零退出，并指出文件名。这样发布前的冻结程序烟测可以发现同类遗漏。
- 先写缺失资源时失败的回归测试；验证旧 spec 构建的程序不能通过新烟测，再修复 spec 并重新构建、验证。
- 应用版本号更新为 3.0.1，补充变更记录和下载说明。保留 v3.0.0 Release 不变，发布新的 Windows exe 与 SHA-256 校验文件。

## 验收边界

源码全量测试、源码烟测、冻结 exe 烟测、Windows 版本资源、GUI 启动、打包资源清单、资产哈希均通过；不将本地设置或生成数据上传。烟测仅验证依赖资源存在，不声称已经完成真实网站爬取或模型出题。
