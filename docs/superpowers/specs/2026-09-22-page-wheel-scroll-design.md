# 生成页滚轮联动设计

## 目标

当“生成”页内容超出窗口高度时，用户可用鼠标滚轮从运行日志区域继续向下查看“原文 ↔ 题目对照”。

## 交互规则

1. 鼠标位于普通页面控件上时，滚轮滚动整个生成页。
2. 鼠标位于日志、题目列表或题目详情等自带纵向滚动的控件上时，优先滚动该控件。
3. 当该控件已在滚动方向的边界、无法继续移动时，同一次滚轮事件改为滚动整个生成页。
4. 页面本身已完全可见时，不拦截控件原有的滚动行为。

## 实现边界

- 仅调整 `app.py` 中生成页的滚轮事件路由；不改变题目数据、布局层级或其他工作区。
- 以离屏 Tkinter 回归测试覆盖：普通控件的整页滚动、内嵌文本控件未到边界时的本地滚动，以及到边界后的整页接力。

## 验收标准

- 在默认窗口尺寸下，页面存在纵向溢出时，从运行日志滚动到底后继续向下滚动可显示第 5 块。
- 题目详情中的长原文仍能在详情框内独立滚动。
- 既有 UI 逻辑检查与全量测试保持通过。
