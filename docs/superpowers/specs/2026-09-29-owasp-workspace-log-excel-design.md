# OWASP 工作区日志与 Excel 入口设计

日期：2026-09-29。用户已确认沿用 TC260 的产物打开方式。

## 目标

让 OWASP 页按顺序呈现「1. 选择 OWASP 风险」「2. 本次生成」「3. 运行日志」「4. 运行结果」。移除「仅在获授权的隔离测试环境使用」勾选项及其启动门禁。结果区提供醒目的「打开题库 Excel」按钮。

## 行为

- OWASP 生成仍使用设置页的 `outputDir`：成功批次自动写入自己的批次目录和 `owasp_prompts.xlsx`，不弹另存为对话框，也不在点击按钮时重新生成或复制 Excel。
- 「打开题库 Excel」复用 TC260 的 `_open_path` 行为，指向当前 OWASP 批次返回的 `xlsxPath`。按钮置于结果区顶部以保持可见；仅当前成功批次有可用路径时启用。新批次开始或失败时立即禁用，避免打开旧批次。
- OWASP 独立运行日志框显示本批次事件，包括时间、阶段、风险编号、消息及警告／错误颜色；不把 OWASP 事件写到 TC260 日志。开始新批次时清空 OWASP 日志；失败时保留已产生的诊断信息并显示最终错误。磁盘 `run.log` 机制不变。
- 日志加入后，整个 OWASP 页沿用 TC260 的纵向滚动容器，使 1280×900 默认窗口和 1020×720 最小窗口仍能完整查看结果表与底部动作，不把结果表压缩成仅一两行。
- 结果表继续保留 `riskId | riskName | userA | userB | prompt | assertion` 六字段；复制、打开 JSON、打开批次目录能力保留。若底部动作栏仍存在，不能再保留第二个同功能 Excel 按钮。

## 验证

Tkinter UI 测试覆盖区块标题、授权控件与门禁消失、生成按钮可用条件、OWASP/TC260 日志隔离、Excel 按钮位置与启停、按钮调用当前批次路径，以及默认／最小窗口的结果表高度和整页滚动。现有 OWASP 管线和 Excel 内容测试继续回归；无需变更导出格式。
