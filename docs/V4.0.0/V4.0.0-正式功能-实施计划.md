# V4.0.0 正式功能实施计划

日期：2026-10-19。用户已批准实施；开发分支：`codex/v4-agentic-top10`。

**Goal:** 在正式 Tkinter 程序新增 Agentic 题集页，用设置页模型生成 ASI01–ASI10 六字段提示词，并交付独立环境文件。

**Architecture:** LLM 与 Agentic 使用版本化目录和同一生成器／批次管线。环境采用程序分配的固定风险配置，模型系统消息提供完整前置条件、工具、注入面和后续动作，最终环境文件从同一配置生成；不允许模型自由创造环境。现有 LLM 接口省略 framework 时仍默认 LLM，LLM02 特有校验不改变。

**Tech Stack:** Python、Tkinter、urllib 兼容聊天接口、openpyxl、unittest、PyInstaller；不增加运行时依赖。

## 明确边界

本轮做正式生成与导出，不制作 Agent 测试执行平台。固定环境配置可约束输入语境，程序的格式／哈希／目录检查不能证明任意模型输出在目标上可执行或代表漏洞；实际工具行为由匹配夹具的人工测试验证。
