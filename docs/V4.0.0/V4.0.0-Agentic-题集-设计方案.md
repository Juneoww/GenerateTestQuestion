# V4.0.0 Agentic 题集设计方案

日期：2026-10-19。状态：用户已确认总体方向；本轮交付原型，正式接入另行实施。

后续状态：用户已批准正式实施，详见[正式功能实施计划](./V4.0.0-正式功能-实施计划.md)。本文以下内容保留为原型阶段的设计基准；“不修改正式入口”等限制仅适用于已经结束的原型阶段。

## 1. 已确认范围

保留当前 TC260 和 OWASP LLM 题集能力，新增独立的 Agentic 标签页。Agentic 最终 JSON 和 Excel 继续只有 `riskId / riskName / userA / userB / prompt / assertion` 六字段，环境信息另存。生成模型、重试、去重、日志和导出能力在正式版中共用。

本轮先制作独立 Tkinter 原型，不修改 `app.py`、现有生成器、应用版本或发布包，不接入真实模型、爬虫或被测 Agent。演示数据始终明确标为“模拟”，不能被理解为真实模型生成结果。

## 2. 信息架构

五个一级标签依次为：`TC260 题库生成 / OWASP LLM 题集 / OWASP Agentic 题集 / 来源管理 / 设置`。Ctrl+1 至 Ctrl+5 切换页面。

原型重点实现两个 OWASP 页；TC260、来源管理和设置仅显示保留位置与说明，不复制现有业务。LLM 与 Agentic 各自保存勾选、数量、语言、日志和结果，切换页面不互相覆盖。原型同步生成演示数据；正式版保持单批次串行执行。

每个 OWASP 页按现有桌面布局组织：

1. 页面说明，显著显示离线原型状态。
2. 风险勾选区，显示编号、中英文名称，支持全选和清空。
3. 数量、语言（中文／英文／中英混合）、选择汇总和“模拟生成”。
4. 页面独立运行日志。
5. 六列结果表，支持双击复制单元格、复制所选 prompt。
6. JSON 预览、Excel 六列预览；Agentic 另有环境说明预览，初始与失败时清空旧结果并禁用动作。

窗口默认 1280×900，最小 1020×720；主内容可滚动，结果表可横向滚动。长文本在预览中完整显示。

## 3. 目录与来源

Agentic 目录采用 [OWASP Top 10 for Agentic Applications for 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/)；编号与语义从[官方发布文章](https://genai.owasp.org/2025/12/09/owasp-top-10-for-agentic-applications-the-benchmark-for-agentic-security-in-the-age-of-autonomous-ai/)及官方 PDF 搜索索引交叉核对。PDF 正文下载超时，本轮不声称完成全文审阅。中文名为项目译名。

| 编号 | 风险名称 | 主要输入位置 | 需要观察的证据 |
|---|---|---|---|
| ASI01 | 智能体目标劫持 | 检索文档／工具返回 | 原任务目标、计划、后续工具调用 |
| ASI02 | 工具滥用与利用 | 用户输入 | 工具名称、参数、调用目的 |
| ASI03 | 身份与权限滥用 | 用户输入 | 已认证身份、委托范围、授权决定 |
| ASI04 | 智能体供应链漏洞 | 组件／工具注册信息 | 来源和签名验证、组件加载决定 |
| ASI05 | 意外代码执行 | 工具返回 | 代码执行决定、沙箱执行日志 |
| ASI06 | 记忆与上下文投毒 | 候选记忆条目 | 写入审核、后续会话读取和行为 |
| ASI07 | 智能体间通信不安全 | 对端智能体消息 | 来源认证、消息完整性、权限检查 |
| ASI08 | 级联故障 | 上游工具／智能体结果 | 错误传播、停止、降级和恢复 |
| ASI09 | 人与智能体信任利用 | 审批建议／任务输入 | 风险呈现、审批内容、实际执行 |
| ASI10 | 失控智能体 | 用户任务输入 | 目标偏离、操作记录、停止和撤销 |

LLM 原型读取当前 `owasp_prompt_generator.OWASP_RISKS`，避免复用旧 v3 原型中已过时的风险顺序。

## 4. 六字段与环境信息

普通记录的 userA、userB 精确为空，prompt 是完整测试输入。LLM02 演示继续使用两个隔离用户会话，prompt 与 userB 完全相同。Agentic 原型全部采用普通六字段记录；记忆、工具返回或对端消息放在 prompt 中，实际投放位置由环境说明标明，不能借用 userA／userB 表示工具返回或两个智能体。

Agentic 环境信息使用独立 JSON 对象，顶层包含 `framework / catalogVersion / mode / records`；mode 为 `prototype-demo`。records 每项包含：

- `recordIndex`：从 1 开始的结果行号，与最终 JSON 顺序／Excel 数据行顺序一致，不计表头。
- `riskId`：与对应六字段记录相同的风险编号。
- `prerequisites`：所需工具、权限、身份、记忆或通信能力。
- `injectionSurface`：实际输入位置，明确用户消息、工具返回、记忆或对端消息等区别。
- `setup`：测试前配置与授权的虚构任务。
- `followUp`：需要后续任务时明确说明；其余为无需后续输入。
- `evidence`：需人工检查的行为或日志证据。

同一风险多行演示使用独立测试标识；环境信息逐行关联。不得仅改变编号却暗示有真实模型多样性。原型不提供文件导出，JSON、Excel 和环境对象均只预览；正式版须把环境文件随 JSON、Excel、manifest 和日志一起原子发布。

## 5. 生成与失败行为

选择至少一项风险；数量为整数、至少等于已选风险数且不超过 1000。按目录顺序平均分配余数，并按风险轮转交错输出。中文、英文和混合模式均有完整演示输入与断言。

开始新一批或参数校验失败时清空本页旧结果与动作状态，不影响另一 OWASP 页。结果先通过现有六字段通用校验器，再进入表格与预览。原型不将演示文本写入正式 output 目录。

## 6. 代码边界

- `prototypes/v4_demo_data.py`：十类 Agentic 演示目录、虚构输入、环境信息、两框架演示生成纯函数。
- `prototypes/v4_native_prototype.py`：独立五页窗口、可复用 OWASP 页组件、复制和预览、无界面自检。
- `tests/test_v4_native_prototype.py`：目录、配额、六字段、跨会话、环境关联、页面隔离、清空和交互验收。
- `docs/V4.0.0/运行-v4-原生原型.bat`：从任意工作目录启动本仓库虚拟环境内的原型。
- `docs/V4.0.0/`：设计、原型计划、正式接入路线、验收记录和使用说明。所有本轮新增文档放在此目录。

原型不引入新依赖；复用现有 Tkinter 和六字段校验，不复用旧原型的过时目录。

## 7. 验收与后续阶段

本轮验收：五页可切换；十类 ASI 可分别及混合生成；LLM02 镜像规则成立；两个 OWASP 页数据隔离；JSON／Excel 预览为六字段；环境逐行关联；非法参数与失败不遗留旧结果；无网络与持久化副作用；全量现有测试回归通过。

后续正式接入：抽出版本化目录和共享引擎，接入后台模型、去重补生成、框架标识、环境文件原子发布，最后升级 4.0.0 并构建 EXE。原型演示通过不能证明提示词已在真实 Agent 上执行或发现漏洞。
