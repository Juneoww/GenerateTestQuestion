# V4.0.0 原生原型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. 本轮由当前会话按用户授权顺序完成；文档审阅使用只读子代理。

**Goal:** 交付可本地启动的五标签 Tkinter 原型，验证独立 Agentic 页、六字段结果和环境信息另存的交互。

**Architecture:** 新增原型数据模块和 UI 模块，不修改正式业务文件。两个 OWASP 页复用同一页面组件，但各自持有勾选、日志、结果与预览状态；数据函数复用当前六字段通用校验器。

**Tech Stack:** Python 3.12、Tkinter/ttk、unittest、现有 `.venv`，不新增依赖。

依据：[设计方案](./V4.0.0-Agentic-题集-设计方案.md)。所有新增文档位于本目录。正式版接入见[正式功能路线](./V4.0.0-正式功能-阶段计划.md)。

**执行状态：** 2026-10-19 本轮原型已完成，文档与代码审阅通过；新增 10 项定向测试、全量 174 项测试通过。操作与限制详见[验收记录](./V4.0.0-原型-验收记录.md)。
